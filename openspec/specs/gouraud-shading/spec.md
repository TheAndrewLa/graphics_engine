# gouraud-shading Specification

## Purpose
Реализует вершинное затенение Гуро с интерполяцией освещённости и цвета по барицентрическим координатам треугольника для гладких криволинейных фигур.

## Requirements

### Requirement: Расчёт освещённости в вершинах
Рендерер SHALL вычислять освещённость каждой вершины треугольника на основе её нормали и источников света.

#### Scenario: Расчёт вершинного цвета
- **WHEN** треугольник содержит нормали в вершинах и сцена освещена источниками света
- **THEN** для каждой из трёх вершин вычисляется результирующий цвет освещения

### Requirement: Барицентрическая интерполяция цвета пикселей
Рендерер SHALL интерполировать цвет пикселя внутри треугольника по барицентрическим весам вершин.

#### Scenario: Плавный градиент освещённости
- **WHEN** растеризуется треугольник с различными значениями цвета в вершинах
- **THEN** цвет каждого пикселя вычисляется как взвешенная сумма цветов вершин без резких перепадов на рёбрах
