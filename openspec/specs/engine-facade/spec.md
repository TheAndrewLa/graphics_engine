# engine-facade Specification

## Purpose
Предоставляет единый высокоуровневый фасад движка для создания игр, связывающий сцену, конвейер кадров, окно, опрос ввода и обратные вызовы симуляции.

## Requirements

### Requirement: Инициализация и жизненный цикл движка
Фасад движка SHALL инициализировать подсистемы по переданной конфигурации и координировать запуск и остановку главного цикла.

#### Scenario: Запуск и завершение главного цикла
- **WHEN** вызываются init с параметрами окна и запуск run
- **THEN** открывается окно, запускается цикл симуляции и рендеринга, а при закрытии окна run возвращает управление

### Requirement: Обратные вызовы игровой симуляции
Фасад движка SHALL вызывать зарегистрированные пользовательские функции на этапах обновления физики/логики, подготовки кадра и событий ввода.

#### Scenario: Фиксированный шаг симуляции
- **WHEN** в процессе главного цикла наступает интервал фиксированного тика времени
- **THEN** вызывается пользовательский обработчик onUpdate с фиксированным шагом dt

#### Scenario: Доставка системного события
- **WHEN** от оконного адаптера поступает новое событие InputEvent
- **THEN** вызывается пользовательский обработчик onEvent с этим событием

### Requirement: Удобное создание объектов в сцене
Фасад движка SHALL предоставлять методы создания 2D и 3D сущностей в активной сцене по типизированным параметрам и по спецификации ObjectSpec.

#### Scenario: Создание объекта через фасад
- **WHEN** пользователь вызывает create с параметрами геометрии
- **THEN** объект регистрируется в активной сцене движка, и возвращается его идентификатор ObjectId
