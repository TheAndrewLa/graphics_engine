# Spec Delta

## Purpose

Реализует софтверную текстурированную растеризацию и вывод 2D-спрайтов с выборкой пикселей по UV-координатам и альфа-смешением.

## ADDED Requirements

### Requirement: Выборка пикселей по UV-координатам
Рендерер SHALL производить выборку цвета из текстурного ImageBuffer в соответствии с нормализованными координатами UV.

#### Scenario: Фильтрация по ближайшему соседу
- **WHEN** запрашивается выборка пикселя текстуры в режиме Nearest Neighbor
- **THEN** возвращается цвет ближайшего целочисленного тексиля буфера

#### Scenario: Билинейная интерполяция
- **WHEN** запрашивается выборка пикселя текстуры в режиме Bilinear
- **THEN** возвращается цвет, линейно интерполированный между четырьмя соседними тексилями

### Requirement: Растеризация 2D-спрайтов с альфа-прозрачностью
Рендерер SHALL накладывать текстурированные прямоугольники и треугольники с учётом альфа-канала тексилей по модели source-over.

#### Scenario: Отображение полупрозрачного спрайта
- **WHEN** выводится спрайт с прозрачными или полупрозрачными областями
- **THEN** пиксели с нулевой прозрачностью отбрасываются, а полупрозрачные пиксели смешиваются с фоном
