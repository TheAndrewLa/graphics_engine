# Proposal

## Why

Huynity использует собственный программный рендерер без внешних графических API (таких как OpenGL или Vulkan), однако текущий набор алгоритмов ограничен плоским заполнением треугольников с попиксельным Z-буфером, базовым flat shading и попиксельным alpha blending. Для создания визуально богатых 2D и 3D игр движку необходимы расширенные рукописные алгоритмы формирования изображения: растеризация линий и проволочных каркасов (wireframe), гладкое вершинное затенение (Gouraud shading) и текстурирование 2D-спрайтов и полигонов с UV-координатами.

## What Changes

- Реализовать рукописный целочисленный алгоритм растеризации линий и отрезков (алгоритм Брезенхэма) для 2D (`Segment2`, `Line2`) и 3D (`Segment3`, `Line3`) с интерполяцией глубины в Z-буфер.
- Добавить режим каркасного отображения (wireframe) для 3D и 2D сетчатых моделей и фигур.
- Реализовать рукописный шейдер Гуро (Gouraud shading): интерполяцию освещённости и цвета вершин по барицентрическим координатам треугольника, сглаживающую гранёность криволинейных поверхностей (`Sphere3`).
- Реализовать текстурированную софтверную растеризацию для 2D-спрайтов и 3D-граней с выборкой пикселей из текстурного `ImageBuffer` по UV-координатам (режимы Nearest Neighbor и билинейная фильтрация).
- Сохранить полную независимость от сторонних графических библиотек: все алгоритмы пишутся на чистом C++23.

## Capabilities

### New Capabilities

- `line-rasterization`: программная растеризация отрезков и каркасных моделей (wireframe) с интерполяцией глубины в Z-буфер и экранные координаты.
- `gouraud-shading`: вершинное затенение с интерполяцией освещённости по барицентрическим весам треугольника для плавных градиентов и гладких поверхностей.
- `texture-mapping`: выборка текстурных данных по UV-координатам с фильтрацией (Nearest Neighbor и Bilinear) и альфа-смешением.

### Modified Capabilities

Существующие спецификации остаются стабильными.

## Impact

- Расширение `engine/renderer`: новые методы в `SoftwareRenderer` и деталях растеризации (`rasterizeLine`, `rasterizeTriangleGouraud`, `rasterizeTriangleTextured`).
- Расширение `engine/render_contracts`: поддержка текстурных ресурсов, UV-координат и режима отрисовки линий/wireframe в `DrawItem3` / `DrawItem2`.
- Производительность проверяется интеграционными тестами и бенчмарками.
