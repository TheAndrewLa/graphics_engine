# Proposal

## Why

Runtime-фабрика возвращает закрытый `Geometry`, но потребитель не может единообразно применить к нему даже поддерживаемые операции: приходится повторять диспетчеризацию по всем альтернативам и отдельно обрабатывать размерность и неподдерживаемые типы. Дополнительно изменяемые Math Point ослабляют гарантию валидности после создания. До появления Core нужно закрепить runtime-контракты, не меняя удачную модель геометрических значений.

## What Changes

- Добавить `bounds(const Geometry&)` с результатом, охватывающим Aabb2 и Aabb3; для Line, Ray и Plane возвращать `UnsupportedOperation`, для пустой сетки — `EmptyGeometry`.
- Добавить `tessellate(const Geometry&, TessellationOptions)` с variant-результатом для Polyline2, TriangleMesh2 и TriangleMesh3. Circle2 делегировать `sampleCircle`, поддерживаемые фигуры — существующим перегрузкам, остальные типы отклонять через `UnsupportedOperation`.
- Сохранить Math Point как изменяемое unchecked-значение. Все новые runtime-операции обязаны проверять фактические данные Point перед вычислением и возвращать `InvalidGeometry` при нечестных координатах; не утверждать, что успех `createObject` гарантирует валидность Point после последующей мутации.
- Закрепить различие между объектами геометрического каталога, результатами операций и render-ready данными. `Geometry` остаётся общим value-вариантом и не становится обещанием поддержки всех операций или отображаемости.
- Зафиксировать координатный контракт: параметрические фигуры с размерами и радиусом остаются локальными и центрированными, объекты с явными точками хранят переданные координаты, а мировое размещение и преобразования экземпляров сцены принадлежат будущему Core.
- Добавить тесты эквивалентности typed/runtime-операций, ошибок, изменённых Point и времени жизни результатов; обновить документацию реализованного API.
- Не добавлять виртуальную иерархию, Scene ObjectId, преобразования сцены, нормали/UV, новые геометрические типы и не менять текущие алгоритмы триангуляции и тесселяции.

## Capabilities

### New Capabilities

- `geometry-runtime-operations`: применение bounds и тесселяции к runtime-варианту Geometry с явной обработкой размерности, неподдерживаемых операций и фактической валидности изменяемых Math Point.

### Modified Capabilities

Нет: основная спецификация OpenSpec пока пуста.

## Impact

Затрагиваются публичные заголовки операций Object Library, реализация runtime-диспетчеризации, тесты `huynity_objectlib_tests` и `docs/objectlib_usage.md`. Существующие typed API и поведение конкретных перегрузок сохраняются; ломающих изменений не предполагается. Новых зависимостей и изменений Core, Renderer или Math не требуется.
