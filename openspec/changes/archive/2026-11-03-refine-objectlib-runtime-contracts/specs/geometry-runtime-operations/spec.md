# Spec Delta

## Purpose

Позволяет потребителям применять геометрические операции к значениям, тип которых выбран во время выполнения, без дублирования полного разбора каталога и с однозначными результатами и ошибками.

## ADDED Requirements

### Requirement: Ограничивающий объём runtime-геометрии
Система SHALL вычислять ограничивающий объём непосредственно для Geometry и возвращать Aabb той же размерности, что и выбранная конечная геометрия.

#### Scenario: Двумерная геометрия
- **WHEN** вызывающий код запрашивает bounds для Geometry, содержащего поддерживаемую 2D-геометрию
- **THEN** результат содержит Aabb2, эквивалентный результату соответствующей типизированной операции

#### Scenario: Трёхмерная геометрия
- **WHEN** вызывающий код запрашивает bounds для Geometry, содержащего поддерживаемую 3D-геометрию
- **THEN** результат содержит Aabb3, эквивалентный результату соответствующей типизированной операции

### Requirement: Ошибки runtime-ограничения
Система SHALL явно отклонять неподдерживаемые или пустые входы и сохранять ошибки типизированных операций без преобразования их в успешный результат.

#### Scenario: Бесконечная геометрия
- **WHEN** bounds запрошен для Geometry, содержащего Line, Ray или Plane
- **THEN** возвращается GeometryError с кодом UnsupportedOperation

#### Scenario: Пустая сетка
- **WHEN** bounds запрошен для Geometry, содержащего TriangleMesh без позиций
- **THEN** возвращается GeometryError с кодом EmptyGeometry

#### Scenario: Нечестная Math Point
- **WHEN** координаты Point внутри Geometry стали нечестными после создания и запрошен bounds
- **THEN** возвращается GeometryError с кодом InvalidGeometry, а не некорректный Aabb

#### Scenario: Variant без значения
- **WHEN** bounds или тесселяция получает Geometry в состоянии valueless_by_exception
- **THEN** возвращается GeometryError с кодом InvalidGeometry без исключения bad_variant_access

### Requirement: Тесселяция runtime-геометрии
Система SHALL выполнять тесселяцию непосредственно для Geometry и возвращать Polyline2 для Circle2, TriangleMesh2 для Disk2 и Rectangle2, TriangleMesh3 для Sphere3 и Box3.

#### Scenario: Контур окружности
- **WHEN** тесселяция запрошена для Geometry, содержащего Circle2
- **THEN** результат эквивалентен sampleCircle для той же окружности и тех же опций и содержит замкнутую Polyline2

#### Scenario: Поддерживаемые заполненные фигуры
- **WHEN** тесселяция запрошена для Geometry, содержащего Disk2, Rectangle2, Sphere3 или Box3
- **THEN** тип и содержимое результата эквивалентны соответствующей типизированной тесселяции с теми же опциями

### Requirement: Ошибки runtime-тесселяции
Система SHALL возвращать UnsupportedOperation для неподдерживаемых альтернатив Geometry и без искажения передавать ошибки опций, бюджета и численных вычислений.

#### Scenario: Неподдерживаемая альтернатива
- **WHEN** тесселяция запрошена для Geometry, содержащего тип без операции тесселяции
- **THEN** возвращается GeometryError с кодом UnsupportedOperation

#### Scenario: Недопустимые опции
- **WHEN** runtime-тесселяция получает опции, отклоняемые типизированной операцией
- **THEN** возвращается тот же код ошибки, что и у типизированной операции

#### Scenario: Недостаточный бюджет
- **WHEN** заданный maxPrimitiveCount недостаточен для выбранной фигуры и точности
- **THEN** возвращается BudgetExceeded без частичного результата

### Requirement: Независимое владение результатом
Система SHALL возвращать результат runtime-операции, владеющий всеми необходимыми данными независимо от времени жизни исходного Geometry.

#### Scenario: Исходный объект уничтожен
- **WHEN** результат bounds или тесселяции получен, а исходный Geometry затем уничтожен или перемещён
- **THEN** данные результата остаются доступными и неизменными

### Requirement: Координатная интерпретация
Система SHALL сохранять локальную центрированность параметрических фигур и исходные координаты геометрии с явными точками во всех runtime-операциях.

#### Scenario: Центрированная фигура
- **WHEN** bounds или тесселяция применяются к Circle2, Disk2, Rectangle2, Sphere3 или Box3 без преобразования сцены
- **THEN** результат вычисляется в локальных координатах относительно начала координат

#### Scenario: Явные координаты
- **WHEN** bounds применяется к Geometry с явно заданными точками
- **THEN** результат использует фактические координаты этих точек без неявного переноса в начало координат
