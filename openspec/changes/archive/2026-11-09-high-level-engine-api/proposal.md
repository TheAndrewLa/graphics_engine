# Proposal

## Why

Huynity обладает всеми фундаментальными подсистемами (математика, геометрия, сцена Core, конвейер кадра Runtime, программный рендерер и оконный адаптер), но создание игры или простого приложения требует от разработчика вручную связывать и координировать более пяти подсистем. Необходим высокоуровневый эргономичный фасад движка (`Engine`), позволяющий создавать игры за минимальное количество строк кода с поддержкой смешанной 2D/3D сцены, коллбеков жизненного цикла и режима мгновенного отображения одиночных объектов.

## What Changes

- Создать высокоуровневый фасад `huynity::Engine` в отдельном модуле или корневом публичном пространстве имён движка.
- Предоставить простой декларативный интерфейс конфигурации приложения (`EngineConfig`: габариты окна, заголовок, частота тика, режим headless/native).
- Реализовать регистрацию пользовательских обработчиков жизненного цикла игры:
  - `onUpdate(double dt)` — шаг фиксированной физики/логики;
  - `onFrame(double alpha)` — покадровая интерполяция;
  - `onEvent(const InputEvent&)` — реакция на события ввода и окна;
  - доступ к `const InputState&` для опроса клавиш и мыши в тике.
- Реализовать удобные фабричные методы создания 2D/3D сущностей прямо через экземпляр движка:
  `engine.create<ObjectType::Box3>(params)` и `engine.create(spec)`.
- Реализовать режим быстрого предварительного просмотра (`quick preview`):
  `engine.preview(geometry)` и `engine.show(objectId)` с автоматическим вычислением AABB, центрированием камеры, добавлением источника света по умолчанию и запуском окна.
- Добавить минимальный эталонный пример игры / демо «Hello, Cube» за 20 строк кода.

## Capabilities

### New Capabilities

- `engine-facade`: фасад игрового движка, координация жизненного цикла (init, run, stop), привязка сцены, окна, ввода и конвейера кадров.
- `quick-preview`: автоматическое конфигурирование сцены и камеры по габаритам геометрии для немедленного вывода объекта на экран в одну команду.

### Modified Capabilities

Существующие спецификации (`geometry-runtime-operations`, `scene-management`, `render-extraction`, `frame-scheduling`, `window-presentation`, `input-dispatch`) остаются неизменными и служат стабильным фундаментом.

## Impact

- Новая публичная цель или компонент: `huynity_engine` / `huynity::engine` (заголовок `<huynity/engine.h>`).
- Зависит от `huynity::core`, `huynity::runtime`, `huynity::renderer`, `huynity::window`, `huynity::image`, `huynity::objectlib`, `huynity::math`.
- Существующие низкоуровневые API не ломаются и остаются доступными для продвинутого использования.
