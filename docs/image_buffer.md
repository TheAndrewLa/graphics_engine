# ImageBuffer

`huynity::image::ImageBuffer` владеет непрерывным массивом байтов изображения. Объект можно перемещать, но нельзя копировать: передача буфера между Renderer, Runtime и Presentation не создаёт разделяемого владения.

## Формат

Начальный формат — `PixelFormat::Rgba8Unorm`. Каждый пиксель занимает четыре байта в порядке R, G, B, A. Значение канала `0` соответствует 0, `255` — 1. Координата `(0, 0)` находится в первом пикселе первой строки буфера; строки расположены сверху вниз.

`width` и `height` задаются в пикселях, `stride` — в байтах от начала одной строки до начала следующей. Нулевой `stride` в `ImageBufferDesc` выбирает плотную упаковку `width * 4`; иное значение не может быть меньше плотной строки. Байты выравнивания между пиксельными данными строк не интерпретируются.

Размер хранилища равен `height * stride`. `bytes()` предоставляет весь буфер, включая выравнивание, а `row(y)` — одну строку длиной `stride`. Вызывающий код должен передавать `y < height`; выход за границы не выполняет неявного чтения или записи, а нарушает предусловие доступа.

Создание через `ImageBuffer::create` отклоняет нулевые размеры, недостаточный stride и переполнение вычисления размера. Доступ к данным перемещённого-from объекта не входит в контракт; после перемещения используется новый владелец.
